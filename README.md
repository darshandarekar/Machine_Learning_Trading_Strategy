# Machine Learning-Based Systematic Trading Strategy — BTC/USD Hourly Data

Research assignment: design, implement, and evaluate an ML-driven systematic trading strategy.

## Summary of Result

A Random Forest classifier (selected via 5-fold expanding-window time-series CV over
Logistic Regression, Random Forest, XGBoost, and an LSTM) predicts the direction of
BTC/USD's next-24-hour return from 28 engineered features. Signals are thresholded into
LONG/SHORT/FLAT and walk-forward backtested (2020-2026, retrained yearly, fully
out-of-sample).

**Headline result:** the strategy underperforms BTC buy-and-hold substantially
(+806% buy-and-hold vs. the strategy's -38% under fixed position sizing). Adding
confidence-based position sizing (Section 10 of the notebook) — a risk-management
change only, not a change to the signal — improves this to roughly breakeven
(+5.3%) with a much smaller max drawdown (-77% -> -21%). Full details, methodology,
and honest discussion of what did and didn't work are in `report/Research_Report.docx`.

## Reproduce the Results

1. Clone this repository and create a virtual environment:
   ```
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # macOS/Linux
   pip install -r requirements.txt
   ```
2. Place the provided price dataset at `data/BTC_price.xlsx` (see note below).
3. Open `notebooks/BTC_Pred_Report.ipynb` and **Restart & Run All**. Expect the LSTM
   training cell to take a few minutes on CPU; everything else runs in seconds to
   low minutes.
4. All intermediate artifacts and charts are written to `results/`.

## Data

The original Excel price file is not committed to this repository (kept local only,

## Notes on Methodology

- All features are strictly backward-looking; the prediction target is the forward
  24-hour return, so there is no lookahead.
- Model selection used cross-validation on the training set only; entry/exit
  thresholds were tuned on a separate validation set only; the final walk-forward
  test (2020-2026) is the sole out-of-sample evaluation, touched once.
- The single-split backtest (validation vs. test) and the walk-forward backtest are
  both included deliberately: the discrepancy between them (validation looked
  profitable, test did not) is what revealed regime-dependence, and is discussed in
  the report as one of the key findings of this research.
